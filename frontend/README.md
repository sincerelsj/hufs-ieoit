# Frontend (Next.js)

담당: FE · 라벨 `FE`

## 화면 (MVP)
- [ ] 조직 선택 → 연도별 아카이브 목록
- [ ] 기록 상세 (원문 링크, AI 요약, 분류 태그)
- [ ] 통합 검색 (자연어 질문 → 결과 + 근거 기록)
- [ ] 인수인계 문서 생성/보기 (로그인 필요)
- [ ] 기록 직접 등록 폼

## 세팅 (프로젝트 생성 후 업데이트)
```bash
cd frontend
npm install
npm run dev   # http://localhost:3000
```
- 백엔드 주소: `NEXT_PUBLIC_API_BASE_URL` (.env)
