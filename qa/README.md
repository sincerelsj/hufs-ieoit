# QA

담당: QA · 라벨 `QA`

## 하는 일
- 사용자 시나리오 작성 → `scenarios/`
- 기능별 테스트 체크리스트 실행, 버그는 **버그 리포트 템플릿**으로 이슈 등록
- 머지 후 재확인
- 발표 데모 시나리오 리허설 (12/9 발표 전)

## 핵심 사용자 시나리오 (초안)
1. **신임 학생회장**: "작년 축제 준비 과정" 검색 → 관련 기록·요약 확인 → 인수인계 문서 생성
2. **학과 조교**: 공지 자동 수집 확인 → 연도별 아카이브에서 지난 학기 공지 찾기
3. **재학생**: "졸업요건" 자연어 질문 → 관련 학사 공지와 요약 확인
4. **권한 없는 사용자**: 내부 인수인계 자료 접근 시 차단되는지
